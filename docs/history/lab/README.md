# The feasibility lab

The experiments behind `../feasibility-study.md`, kept as history. The
player does not use any of this: what grew out of it lives in `player/`
(`minimal/run.js` became `player/js`, `overlays/` became `player/patches`,
the `device-*.sh` runs became `player/tests/device`).

The scripts expect to be run from a folder named `lab/` at the top of the
repository, next to a copy of a game in `lab/game/`, and write to
`lab/out/`; neither was ever in the repository.
